How to add any agent

Most agents have a ZIP file and a guide. In short:

  1. Download the agent's ZIP file.
  2. Go to Customize > Skills, click + Add, choose Upload a skill, and pick the ZIP.
  3. Switch it on, then follow that agent's guide.

Some agents, like the advisory council, are connectors: you paste one link into Settings > Connectors and there is nothing to download. Their page shows the link.

You need a Claude Pro or Max plan. If Skills is greyed out or there's no upload option, open Settings > Capabilities and turn on code execution.

Make it your own

Every agent is yours to change. Open the skill folder, read the instructions, and adjust them to fit how you work.
