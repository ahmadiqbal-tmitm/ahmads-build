How to add any agent

Each agent has a ZIP file and a guide. In short:

  1. Download the agent's ZIP file.
  2. In Claude, turn on Code execution and file creation under Settings > Capabilities.
  3. Go to Customize > Skills, click +, choose Create skill, then Upload a skill, and pick the ZIP.
  4. Switch it on, then follow that agent's guide.

You need a Claude Pro or Max plan.

Make it your own

Every agent is yours to change. Open the skill folder, read the instructions, and adjust them to fit how you work.
